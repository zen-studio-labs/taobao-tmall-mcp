# Changelog

## 0.1.0

First release.

- Remote MCP server with three Taobao (淘宝) and Tmall (天猫) tools: product search, item details with optional buyer reviews, and shop product lists.
- Apify sign-in (OAuth) for Claude, ChatGPT, Cursor, VS Code, Codex and other remote MCP clients; token header as an alternative.
- Claude Code plugin with the Taobao skill: run flow for longer requests, input recipes, tool chaining and field sets.
- Client configuration examples, code examples for Python, JavaScript and HTTP, and an MCP Registry manifest.
- README in English and Simplified Chinese.
